# Interior spatial evidence

**Decision question:** What observed dimensions/layout evidence can support a concept fit hypothesis and what must be measured/verified?

**Sources:** Matterport Model API, official docs <https://developers.matterport.com/api/>; CoStar starter CSV model IDs.

**Preliminary:** A bounded batch of commercial model IDs returned records for nearly all requested IDs, with one `not.found`. Defurnished-view metadata was queried for shortlist-linked models; only a subset returned locations. The user selected the pilot tour, but the marketed suite-to-scan identity and dimensions remain unverified; model and listing area fields materially disagree.

**Prep:** preserve source dimensions/units and model timestamp; verify room geometry and dimension fields against an actual floor plan/measured reference; map listing suite to model, doors/egress/utilities and scan capture scope; distinguish observed/model-derived/unknown; build a visualized zoning hypothesis only.

**Do not claim:** code-compliant fit, equipment absent/present, current condition, or dimension validation from scan metadata alone.
