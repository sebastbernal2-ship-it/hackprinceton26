# Mobility, tourism, and temporal activity

**Decision question:** How does people/activity presence vary by day, season, and event near the candidate, and is it relevant to the service model?

**Candidate sources:** Visit Houston and Los Angeles Tourism & Convention Board public research; city event calendars; BTS/NTTO travel statistics; transit ridership/GTFS; Census LODES; official pedestrian counts where published. Vexcel imagery is not a reliable footfall source.

**Preliminary:** No visits, footfall, tourism, or event datasets fetched. No candidate trade-area match verified.

**Prep:** separate city/metro tourism totals from site-level visits; request licensed mobility data only with privacy/aggregation terms; identify public pedestrian count station coverage; align time windows with candidate hours, seasonality, and concept. Store provenance and suppression rules.

**Do not claim:** site-level visitors, conversion, or demand from metro arrivals, nearby events, image detections, or residential population alone. Do not infer individual movement.
