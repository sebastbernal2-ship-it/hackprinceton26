# Registry usage

`sites.csv` and `sources.csv` are local-only working registries and are gitignored because populated records may contain sponsor identifiers, addresses, or credential metadata. Use this document as the schema guidance; commit only empty templates or synthetic examples. Add candidate records only with team approval, prefer stable site IDs, and mark unresolved matches rather than inventing IDs.

Track source access separately from public documentation. Do not mark access confirmed until the sponsor has supplied authorization or a working approved sample. Secret inventory is not proof of access.
